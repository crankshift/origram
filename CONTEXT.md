# Origram

Origram is an Xposed module (for Vector/LSPosed) that changes how the official Telegram Android app behaves, one opt-in improvement at a time.

## Language

**Target App**:
An official Telegram Android build: the Play Store, standalone (telegram.org), or beta release.
_Avoid_: client, Telegram X, fork

**Tweak**:
One self-contained behavior change to the Target App that the user can switch on or off.
_Avoid_: feature, patch, mod, hack

### Ads

**Ad**:
Any promotional content that Telegram adds to the Target App without the user asking for it, whether a third party paid for it or Telegram placed it for its own promotion.
_Avoid_: sponsored content (as the umbrella term), promo

**Ad Removal**:
The Tweak that stops Ads from appearing.
_Avoid_: ad block, anti-ads

**Sponsored Message**:
A paid Ad shown as a message inside a channel, a bot chat, or the media viewer.
_Avoid_: sponsored post, native ad

**Sponsored Peer**:
A paid Ad that shows a chat, channel, or bot in search results.
_Avoid_: sponsored search result

**Promo Chat**:
A chat pinned to the top of the chat list that the user never asked for, whether a proxy operator's sponsored channel or a Telegram public service announcement (PSA).
_Avoid_: proxy promo, proxy sponsor, PSA chat

**Channel Suggestion**:
An unrequested recommendation of other channels, such as "Similar channels".
_Avoid_: recommended channels, related channels

**Premium Promo**:
A banner, prompt, or badge that pushes the user to buy Telegram Premium.
_Avoid_: premium nag, upsell
